Export CSV

Export your media items, scores, notes, progress, dates and collections. Image files are not included. Scores use the 0–100 scale.

Formula-like text is protected for spreadsheets. Media Journal restores the original text when re-importing this CSV.

Import CSV

Upload one item per row, map the columns, then review matches before importing. Viewing history is not imported. Existing items are kept unchanged; for duplicate rows, the first imported entry is kept.

Up to 50 MB and 50,000 items per file. Paused transfer data is kept for 7 days.

Import and export may not work as expected in every situation. If you run into a problem, please open an issue.

Match Columns

Ignore columns you do not want to import. JSON arrays also work for list fields. Blank or zero numeric scores mean unrated. Progress values are whole episodes, seasons, chapters, volumes, pages or hours; movie length is in minutes.
